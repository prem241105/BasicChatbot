 Basic Chatbot

## What it does
- Reads messages from the console.
- Uses `if`/`elif`-style rule matching in a function to select replies.
- Supports greetings, asking how the bot is, asking its name, help, thanks, time, and goodbye.
- Runs until the user exits.

## Requirements
- Python 3.9 or newer
- No third-party packages required

## Run
```bash
python main.py
```

## Example
```text
Bot: Hello! Type 'help' for ideas or 'bye' to exit.
You: hello
Bot: Hi! Nice to meet you. How can I help?
You: how are you
Bot: I'm fine, thanks! How are you?
You: bye
Bot: Goodbye! Have a great day!
```
